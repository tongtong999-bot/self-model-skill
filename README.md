# Self Model · 观己

**从一件真实经历开始，理解自己的选择，再找到一个可以尝试的小行动。**

一个中文优先的 AI Skill，将自我访谈、情境演练、人物路径比较和行动复盘串成对话。使用你已有的 AI；无需部署网站、购买域名或配置本项目的 API Key。

A conversational Agent Skill for self-understanding, decision exploration, and reflective action. Chinese-first; responds in the user's language.

[查看 Skill](skills/self-model/SKILL.md) · [看一段虚构体验](examples/conversation.md) · [下载安装包](https://github.com/tongtong999-bot/self-model-skill/releases/latest)

**v0.2 已补齐原网站的完整探索内容和本地记录机制。** 可以轻聊，也可以按原版 24 题、三套五轮情境、五个四轮访谈主题逐步完成；有 Python 和文件工具时自动记录进度、检查报告、导出私人阅读版。

**第一次用，不知道怎么开始？** 启用后可以直接说“我想认识自己，不知道从哪里开始，请用观己带我试试”。AI 会逐步提问，说明每一步怎么回答、接下来可以做什么。支持自动选择 Skill 的客户端可能直接调用；如果没有触发，在客户端选中“Self Model · 观己”，或在 Codex 中输入 `$self-model`。安装本身不会自动弹出欢迎对话。

## 最快开始：在 Codex 中使用

**第一步：把下面这段话发给 Codex。**

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/tongtong999-bot/self-model-skill/tree/main/skills/self-model
如果已经有同名 Skill，请先告诉我，不要覆盖。
```

**第二步：安装完成后，在下一轮对话输入一句话即可：**

```text
使用 $self-model，带我开始。
```

**第三步：跟着引导回答。** AI 会简要介绍玩法，让你从“最近一件小事”“系统探索”“继续已有档案”中开始；你可以回复编号，也可以直接说自己的困扰。不知道选什么，就说“你带我”，AI 会从一个简单问题开始。每轮只推进一个主要问题。

可以随时说“跳过”“这个判断不对”“换个情境”“先总结”或“暂停”。不必先填完整套问卷。

只想轻聊时，直接说“从最近一件困扰开始，不做整套题”。需要跨对话继续时，告诉 AI 保存到自己的私人文件夹；以后指定同一份档案即可续接。AI 会负责操作记录工具，不需要你写命令或 JSON。

**第四步：由 AI 提示下一步。** 聊完一段后，它会简要总结并建议继续访谈、试一个情境、比较人物路径或设计小尝试，解释为什么这一步有帮助。你可以接受，也可以换方向。想直接深入时，也可以这样说：

```text
根据我们聊过的内容，整理当前的自我模型。
找三位不同行业的历史或当代人物作为参照，查阅来源，
比较他们的选择、与我的差异，以及我可以试的三条方向。
最后给我一个这周能开始的小尝试。
```

安装器会使用当前 Codex 的 Skill 目录。若当前客户端没有提供安装器，可下载仓库，并将整个 `skills/self-model` 文件夹放入该客户端配置的个人 Skill 目录，不能只复制 `SKILL.md`。

**已安装旧版？** 可以对 AI 说：“请用这个仓库的最新版更新 self-model，先检查安装目录有没有我的自定义修改；保留私人档案和修改，不直接覆盖冲突文件。”下载的旧 ZIP 不会自动更新，需要重新安装新版。

## 其他使用方式

### Claude Code

将以下文字发给有文件和网络权限的 Claude Code：

```text
请从 https://github.com/tongtong999-bot/self-model-skill
下载 skills/self-model 文件夹，安装到 ~/.claude/skills/self-model。
保留所有参考文件。如果该目录已存在，不要覆盖，先告诉我。
```

随后输入：

```text
/self-model 从我最近的一件困扰开始，帮我理解自己，并找到一个可尝试的小行动。
```

目录和调用方式见 [Claude Code 官方 Skill 文档](https://code.claude.com/docs/en/skills)。

### Claude 的自定义 Skills

从 [Releases](https://github.com/tongtong999-bot/self-model-skill/releases/latest) 下载 **`self-model.zip`**，在 Claude 的自定义 Skills 界面上传并启用，然后说“请用 self-model 帮我认识自己”。上传的是这个专用包，不是 GitHub 自动生成的整个仓库源码 ZIP。

需要账户具有对应功能并启用代码执行，具体入口以 [Claude 官方说明](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) 为准。增强记录工具只使用 Python 3.9+ 标准库，无需安装第三方包。Claude 临时执行环境中的档案应及时下载，下次提供；不要假定平台一直保留运行文件。

### 其他 AI 聊天工具

如果工具能读取文件，可以解压安装包，将 `SKILL.md` 和这次需要的参考文件作为附件提供，并要求按其流程对话。这属于手动使用，**不代表工具已安装 Skill 或拥有跨会话记忆**。无法读取附件时，可复制相关文本。

## 它可以帮你做什么

| 你可以说 | 会如何开展 |
| --- | --- |
| “我想认识自己，不知道从哪里开始” | 从一个近期事件开始，逐步了解做法、条件和在意的东西 |
| “按原网站的完整流程开始” | 原版 24 题、三套五轮情境、五个访谈主题；逐段记录进度 |
| “给我一个情境，看看我怎么选择” | 进行明确标注为虚构的演练，回看权衡过程 |
| “我为什么总在同类事情上纠结？” | 对照经历与反例，提出可以修正的解释 |
| “找三位人物，看看有哪些发展方向” | 动态选择跨领域人物，查阅事实，说明相似处、关键差异和路径代价 |
| “别只分析，我这周可以做什么？” | 比较少量选择，形成一个适合当前资源的小尝试 |
| “这是我试过以后的结果” | 比较预期与实际，更新理解，允许调整和暂停 |
| “读取这份档案，继续上次进度” | 读取已答题、当前情境和访谈轮次、修正与暂停状态 |
| “导出一份我能直接阅读的报告” | 从当前档案生成含依据、路径、行动与复盘的私人 Markdown 文件 |

它不会预装一份“你就是某某名人”的名单。人物来自当前 AI 对具体资料的分析；有联网能力时查阅出处，没有时明确标为待研究候选。人物故事用于拓宽选择，不能预测人生。

## AI 在哪里起作用

Skill 是一套可复用的工作方法，**运行它的 AI 负责访谈、理解、提出假设、检索人物资料、比较路径和整理行动**。本地程序负责固定题目、情境资源变化、证据归组、文件保存和结构检查。分析质量仍依赖使用的模型及其可用工具。

本项目没有独立服务器、共享密钥、账号系统或付费解锁。公开内容采用 MIT 许可；使用 AI 产生的订阅或 API 费用由使用者自己的平台收取。已经在 Codex 或 Claude 中对话时，无需为这个 Skill 再接一次 GLM API。

## 如何保留自己的记录

默认在当前对话中工作。希望下次继续时，告诉 AI：

```text
请把这次的关键经历、当前理解、我的修正和行动状态保存成个人档案。
只保存必要信息，放到我指定的私人文件夹，不要放进 Skill 目录或 GitHub 仓库。
```

然后提供自己的保存位置，例如自己“文稿”中的一个私人文件夹。有执行环境时，AI 会保存一份 JSON 档案并在你授权的范围内持续更新；下次指定它即可。没有文件工具时，让 AI 给出带进度的摘要，自己保存并在下次提供。模板见 [个人档案模板](skills/self-model/assets/profile.md)。

原网站导出的 `version: 1` 原始档案 JSON 也可以交给 AI 导入新文件。它会保留原始经历和示例标记，旧 AI 报告需要基于新资料重新生成；不会自动搬迁账户或支付状态。v0.1 的 Markdown 档案可以由 AI 辅助整理，但未曾回答的问卷题目不会被自动补上。

修改、纠正或删除资料后，旧整合报告会作废。删除按来源处理，可能连带移除依据该来源生成的行动与复盘，执行时会说明范围；其他导出副本和平台聊天需另行处理。

本项目不自建数据收集服务，也不要求上传档案给作者。但与 AI 的对话、文件读取和搜索仍受所用平台的数据规则影响，不能把“本地文件”理解成“模型完全离线”。请用化名或省去无关身份信息；不要把真实经历和隐私放到公开 Issue 中。

## 方法与边界

工作方法借鉴人格与情境研究、叙事身份、社会学角色理论、自我调节和实施意图；具体依据及本项目自己的设计判断见 [方法说明](skills/self-model/references/methods.md)。

这是自我探索与行动支持工具，**不是心理诊断、标准化人格测验或效果经过验证的治疗方案**。问答、模拟、经历自述和现实记录会区分来源；不生成虚构的准确率或人格相似度。用户可以纠正解释，AI 应同步调整建议。

## 项目结构

```text
skills/self-model/
├── SKILL.md                       对话入口与共同规则
├── agents/openai.yaml             Codex 展示信息
├── data/catalog.json              原网站完整题库、情境与维度
├── scripts/
│   ├── self_model.py              档案、进度、报告检查与导出
│   └── model.py                   网站情境与证据计算规则
├── references/
│   ├── full-exploration.md        完整探索与续接方式
│   ├── runtime.md                 本地工具用法，供 AI 读取
│   ├── exploration.md             经历、问答与情境演练
│   ├── portraits.md               完整解析与人物路径
│   ├── action-and-review.md       行动与复盘
│   └── methods.md                 方法依据与限制
└── assets/profile.md              可选个人档案模板
examples/conversation.md           完全虚构的体验示例
```

对话模式无执行依赖；增强模式需要宿主能运行 Python 3.9+ 并访问你指定的文件。完整对齐范围和验证结果见 [与网站的对照说明](docs/WEBSITE_PARITY.md)。兼容格式不代表在每个 AI 客户端上都做过实机测试；Claude 客户端尚未实机验证。

维护者可执行 `python3 -m unittest discover -s tests -v` 运行合成资料测试。测试不读取真实档案或 API Key。网站对照基准来自原网站执行结果，包含全部固定情境选项；仅作为代码规则回归，不能证明心理效果或不同模型的输出一致。
