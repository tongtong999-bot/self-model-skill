# 完整探索：沿用网站的题目与过程

当用户要求“像网站一样完整做一次”“从头系统了解自己”或继续完整探索时读取。轻量对话不必走这条路径。

## 运行与续接

有 Python 3.9+ 和文件工具时，按 [runtime.md](runtime.md) 使用本地记录工具。每轮操作前读取当前状态；先处理未完成的问卷、情境、访谈或行动，再提供下一步。用户已允许保存到指定私人档案后，后续回答可持续写入，无需每轮重新征求同样授权。保存失败时先保留用户本轮回答，不声称已经记住。

无执行工具时，可从 [catalog.json](../data/catalog.json) 读取同一套内容，用对话与 [档案模板](../assets/profile.md) 保留原题编号、当前节点和回答。只能说人工整理，不能声称通过了程序校验；不要让 AI 心算资源变化后冒充固定引擎的验证结果。

首次只需知道用户当前想解决的问题、希望保留的东西及主要限制。以下是推荐顺序，用户可以换序、暂停、跳过或提前看局部分析：

**24 题基线 → 任选一套五轮情境 → 任选一次四轮访谈 → 当前模型与反例 → 人物路径 → 一次小尝试 → 复盘。**

## 1. 原版 24 题基线

读取工具 `catalog --section baseline`，按原文和 b1–b24 编号提问。回答沿用网站五档：1 非常不符合、2 比较不符合、3 不确定/居中、4 比较符合、5 非常符合。默认一题一答；用户愿意加快时可四题一组。

- 未答、跳过与“3”不同。只有用户实际选择“不确定/居中”才能记为 3。
- 用户讲了一段经历时，可以保留经历，不替用户猜一个数值。需要数值才能记入固定基线时，简短确认其选择。
- 可修改已答题。每次更新同一题，不增加题目数量或额外独立证据。
- 24 题都回答后完成基线。用户不想做完就停在已答进度，继续其他探索。
- 题库中的反向题标记交给程序处理，不改题、不向用户暗示“高分答案”。

这是原创反思题，不是标准化心理量表。15 个维度的高低都不是优劣或智力道德等级。

## 2. 三套各五轮的原版情境

| 编号 | 名称 | 角色与问题 |
| --- | --- | --- |
| flood | 洪水之后 | 新任县令：粮食、分配、关系、规则与长期秩序 |
| command | 迷雾中的信号 | 救援协作队指挥官：有限资源、信息冲突与不可逆选择 |
| startup | 六个月之后 | 创业公司 CEO：现金、增长、控制权和团队承诺 |

全部为架空演练。每一轮：

1. 用 `show --run` 获取本轮叙事、条件变化、选项和可询问信息。只呈现当前轮，不泄露后续答案、假设权重或结果。
2. 用户主动询问信息时调用 `scenario.request`，再呈现该答案。不要一次展示所有答案并把它记成用户主动搜集。固定资料回答不了的问题应明确未知。
3. 记录用户选项或自定方案、理由、其明确表达的最在意因素；预期可选。把自然语言因素映射到题库维度时要有明确依据，歧义就询问，不替用户决定偏好。
4. 调用 `scenario.decide`，按程序结果呈现资源变化和后果，明确这是演练规则。自定方案不擅自生成资源增减。
5. 保留用户原本的预期，比较的是“预测与模拟规则结果”，不能称为现实验证。进入下一轮，用户可以中途暂停。

固定模式的理由至少 8 字，自定方案至少 5 字；若用户不想补充，允许停在这里或转轻量讨论，不代写理由凑长度。五轮结束后回顾最主要的权衡、一个相反解释，以及现实中是否有反例。同一选择与理由只属于一个事件组。

## 3. 五个主题、每次四轮经历访谈

主题沿用网站：风险选择（risk）、严重分歧（conflict）、利益与原则（principle）、信息不足（unknown）、判断改变（mistake）。近期随手记录（recent）单独保存，不代替完整访谈。

首问使用主题原文，后续由宿主 AI 根据用户回答追问；不用固定台词覆盖已经说过的内容。四轮关注点分别为：

1. 具体事件、实际选择与结果。
2. 当时的信息、感受、替代方案、角色和资源限制。
3. 用户当前怎样解释，以及还有什么解释、什么条件会改变选择。
4. 后续与原预期的差异、相似情境中的反例，以及下一次想探索什么。

每轮一个主问题。用户一次已回答多个方面时，追问最影响判断的空缺；不能把 AI 自己补写的段落算成用户的四轮回答。用户不愿继续时保持部分完成，不以凑满四轮为目的。若用户主动选择了最在意的因素，可记录为自述线索，不让 AI 代选。

## 4. 自我模型、矛盾和变化

使用 `model` 获取 15 维观察与来源编号；展开少量最有依据的线索，不把空维度硬填满。需要全貌时给表格：维度、目前观察、适用情境、原始依据、反例/待了解。

优先区分：我怎样描述自己、我在模拟中怎样选择、我怎样回忆现实经历、实际尝试报告了什么结果。自述与情境不同不意味着用户不诚实。固定引擎没有理解访谈全文，访谈的深入解释仍由 AI 完成；不要把没有自动维度信号误读成“这段经历没价值”。

可以用“之前认为 → 新增材料 → 现在收窄或修正的理解”展示更新。原始规则中的权重和置信字段是未校准的启发值，程序默认不展示成分数、概率或准确率；不要以它们压过用户的事实纠正。

完成基线、一套情境和一次访谈后，已有三类不同材料，可建议做整合报告。**这只是参考时机，不能作为必须做完、付费或准确率门槛。** 只做其中一部分也可以进入 [人物路径](portraits.md) 或 [行动复盘](action-and-review.md)。
